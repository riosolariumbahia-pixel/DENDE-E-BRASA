DENDE E BRASA

Este repositório agora contém uma página estática placeholder para permitir o deploy imediato no Vercel.

Substitua o conteúdo deste arquivo index.html pela versão final do site (HTML, ou um framework suportado como Next.js) para publicar o site institucional.

Como publicar no Vercel agora:
1) Vá para https://vercel.com/import/git e conecte sua conta GitHub.
2) Escolha o repositório riosolariumbahia-pixel/DENDE-E-BRASA e clique em Deploy.
3) O Vercel detectará esta página estática automaticamente e fará o deploy.
